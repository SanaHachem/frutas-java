Descrição do Projeto

Projeto desenvolvido em Java para simular um sistema simples de compra de bananas, utilizando conceitos de Programação Orientada a Objetos (POO).

Funcionalidades

* Pré-cadastro de três clientes.
* Lista com três tipos de bananas: Nanica, Prata e Maçã.
* Controle da quantidade disponível de cada banana.
* Seleção de um cliente cadastrado.
* Escolha da banana e da quantidade desejada.
* Simulação de compra pelo terminal.

Classes Utilizadas

* Frutas.java: armazena o nome e a quantidade da fruta.
* Banana.java: herda os atributos da classe Frutas.
* Cliente.java: realiza o pré-cadastro dos clientes.
* Principal.java: executa o sistema e permite realizar a compra.

Como Executar

Compile os arquivos Java:

javac *.java

Execute o programa:

java Principal
